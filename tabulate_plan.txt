# tabulation levels for symbols

valued
TYPE1: global_variable, procedures
level 0: tabulated - name was evaluated and symbol is in symbol table
level 1: resolved - the outside facing info is resolved (signature, type, etc)
level 2: implemented - the non-outside facing info is resolved (initial value, rqir, etc)

object
TYPE2: class, enumeration, category
level 0: tabulated
level 1: implemented
(no resolved stage)

eager
TYPE3: static_variable, local_variable, code
level 0: tabulated
(everything is done at once)

# move semantics vs actual

int is a value of size that fits in a register
struct is a value of a type that does not fit into a register or has stable_address attribute
after a .[move] the existing variable is invalidated and data has new memory address
after a .[borrow] the existing variable still exists and address is same

var := int.[move];      ->  copy int data to var
var := struct.[move];   ->  copy struct data into var
func(int.[move]);       ->  copy int data as arg
func(struct.[move]);    ->  copy to new address then pass address as arg
int.[move].meth();      ->  copy int data as this
struct.[move].meth();   ->  copy to new address then use address as this

var := int.[borrow];    -> copy pointer to int to var
var := struct.[borrow]; -> copy pointer to struct data into var
func(int.[borrow]);     -> copy pointer to int as arg
func(struct.[borrow]);  -> copy pointer to struct data as arg
int.[borrow].meth();    -> copy pointer to int as this
struct.[borrow].meth(); -> copy pointer to struct as this
